# Session Handoff & ChatGPT Status Pack

Before proposing a new Codex or ChatGPT session, ensure evidence for: current task state, Git state, checks, project memory sync, next action. Do not claim completion if not confirmed.

```text
AI DEVELOPMENT OS — STATUS PACK
Project / repo: ...
Methodology version (tag/commit): ...
Current phase: ...
Confirmed requirements / approved decisions (IDs): ...
Architecture & stack: ...
Task state / pending work: ...
Last verified result + checks: ...
Git branch, last good checkpoint, uncommitted changes: ...
Files to consult next: ...
Risks / open blockers: ...
Next concrete action: ...
```

For a new Codex session, issue a short instruction to read AGENTS.md, PROJECT.md, active TODO and only task-relevant documents. Avoid copying entire past conversations.
